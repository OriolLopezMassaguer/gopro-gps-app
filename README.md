# GoProGPS

Early-stage Android companion app for GoPro GPS visualization — the mobile counterpart to [mapa_gopro](../mapa_gopro/).

## Status

Project scaffold. Active development not yet started.

## Stack

- Kotlin, Android
- Gradle 8.2.2, Kotlin 1.9.22
- Repositories: Google, MavenCentral, JitPack

## Build

```bash
./gradlew assembleDebug
```
